# dm_RAG

デュエル・マスターズのカード情報をCSVに保存し、能力テキストから検索するプロジェクトです。

## パック単位のカード追加

`card_import.py` は、指定パックの公式一覧とWikiの収録番号・カード名を照合し、
手元のCSVにないカードだけ公式詳細から取得します。並び順には依存しません。

```powershell
# まず候補数を確認。詳細ページは取得しません。
poetry run python card_import.py DM25-RP1 --existing card_data/duelmasters_cards_20250501.csv

# 詳細取得を実行。新規カードだけを別CSVに保存します。
poetry run python card_import.py DM25-RP1 --existing card_data/duelmasters_cards_20250501.csv --fetch
```

比較元のCSVは `--existing` で明示してください。上のファイル名は既存データを使う例です。
通常名のCSVと検索用indexには件数差があるため、自動選択しません。
DM25-RP1の既存一覧119件は、上の比較元では全件登録済みと判定されました。

出力先は `card_data/new_cards_25rp1.csv`、候補URL・件数の記録は
`card_data/new_cards_25rp1.report.json` です。`--output` で変更できます。
すでに出力済みのカードも除外するため、同じコマンドで途中から再開できます。
既存CSV・検索用indexは変更しません。差分CSVを検索に使うための結合・index更新は別工程です。

### サイトへの負荷を減らす仕組み

- Chromeを起動せず、必要なHTMLだけ取得します。画像・CSS・広告・JavaScriptは取得しません。
- パックのWikiを1ページ、公式一覧を必要ページ分だけ取得し、登録済みの名前を詳細取得前に除外します。
- 全半角・空白・引用符の表記差を吸収し、絵違い・レアリティ違いは同じ名前として扱います。
- HTMLは `.card_cache/` に保存します。再実行や解析処理の修正で取り直す必要はありません。
- 新しい通信の間隔は最低2秒。`--delay 5` のように長くできます。並列取得はしません。
- 通信エラー時は自動再試行を重ねず停止します。取得済みHTML・完成済みの差分行は残ります。

一覧も保存するため、発売前の追記などを反映したいときは `--refresh-lists` を指定します。
このオプションはWikiと公式一覧を再取得し、取得済みの詳細HTMLは再利用します。
詳細も意図的に更新する場合は、出力CSVを保管した上で別の `--cache` と別の出力先を指定してください。

### 特殊な収録番号

公式URLを推測して生成せず、公式一覧にある実在URLとWikiの番号を対応させます。
DM25-RP1（144件）・DM24-EX4（180件）で、絵違い等を含む全324件の番号が対応することを確認済みです。

| Wiki側の番号 | 公式URLの末尾の例 |
| --- | --- |
| `1` / `S1` | `001` / `S01` |
| `TR3` / `TD1` / `PR1` | `TR03` / `TD01` / `PR001` |
| `㊙1` | `Sec01` |
| `㊙1超` | `ChoSec001` |
| `DM1㊙` | `SecDM1` |

1つのWiki行に複数の番号がある場合も読み取ります。ツインパクトは両面を含む名前で比較します。
未知の番号は黙って除外せず、取得候補に残して記録します。
Wikiと公式詳細の名前が一致しない場合、または情報が欠けた場合は停止します。
他のパックの番号をすべて検証したわけではありません。

`DMRP-22` など旧形式のパックコードも受け付けます。
Wikiのページ名が通常の形式と異なる場合は `--wiki-page DM25-RP1` のように明示できます。
少数だけ試す場合は `--fetch --limit 1` を使えます。

### 旧ノートブックから使う場合

`make_card_csv.get_card_urls_from_pages(products="25rp1")` もHTMLだけの取得に変更済みです。
ただし、旧来の「一覧URLを全部取得 → 詳細取得」はWikiによる事前除外を行いません。
通信を減らすには上の `card_import.py` を使用してください。
`add_card_list_to_csv` の `max_retries` 引数は呼び出し互換のため残していますが、
通信失敗時はその場で停止し、再開は同じ呼び出しを再実行します。

## 検証

実行にはPython 3.12以上、Poetry管理の依存関係が必要です。
`poetry install --no-root` で環境を準備できます。取得処理はOpenAI APIを呼びません。
回帰テストはpytestを導入した環境で `poetry run python -m pytest tests/test_card_import.py` を実行します。
